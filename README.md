# 🌱 EcoMind AI

## Multi-Agent Sustainability Intelligence System

EcoMind AI is an AI-powered sustainability intelligence platform that analyzes energy consumption, detects anomalies, identifies root causes, predicts savings, evaluates environmental impact, and generates actionable sustainability recommendations using a multi-agent architecture.

---

## 🚀 Features

* 📊 Energy Consumption Analysis
* 🔍 Anomaly Detection Agent
* 🎯 Root Cause Analysis Agent
* 💡 Recommendation Agent
* 💰 Savings Prediction Agent
* 🌍 Sustainability Score Calculation
* 🧠 AI Reasoning Engine
* 🤖 Gemini-Powered Sustainability Assessment
* 🎯 Confidence Scoring Agent
* 🔮 What-If Scenario Simulator
* 📄 Executive Summary Generator
* 📈 Interactive Streamlit Dashboard
* 🌙 Modern Enterprise-Grade UI

---

## 🏗️ Multi-Agent Architecture

EcoMind AI consists of specialized AI agents:

1. Context Agent
2. Investigation Agent
3. Root Cause Agent
4. Recommendation Agent
5. Savings Agent
6. Sustainability Score Agent
7. Confidence Agent
8. Executive Summary Agent
9. Gemini Sustainability Report Agent

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Harshitha-Somu/EcoMind-AI.git
cd EcoMind-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run streamlit_app.py
```
